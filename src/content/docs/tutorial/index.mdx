This tutorial starts with a tiny Process from the `juiz pkg create` skeleton that just adds two numbers, and grows that example little by little to teach you how juiz thinks.
Each chapter is built around running things yourself, so you can follow along with your hands on the keyboard.

## Chapters

<Steps>

1. **[Your first Process](/tutorial/first-process/)** ([Rust](/tutorial/first-process/rust/), [Python](/tutorial/first-process/python/), [C++](/tutorial/first-process/cpp/), [Haskell](/tutorial/first-process/haskell/), [Zig](/tutorial/first-process/zig/))

   Create a project skeleton with `juiz pkg create`, read the code of its Process that adds two numbers, run it, and call it from the web UI and from a terminal to get the result back. You learn how to read the skeleton, that a Process is an idempotent function, and how to use it with call.

2. **[Keeping state: Container and ContainerProcess](/tutorial/container/)** ([Rust](/tutorial/container/rust/), [Python](/tutorial/container/python/), [C++](/tutorial/container/cpp/), [Haskell](/tutorial/container/haskell/), [Zig](/tutorial/container/zig/))

   Add a counter with `juiz pkg add container`, and learn a design where state lives in a Container and only ContainerProcesses touch it.

3. **[Starting everything from a configuration file](/tutorial/config-file/)** (all languages)

   Read the skeleton's configuration file `app/app.conf` and edit it to add instances and pass initial values. You learn the difference between loading (plugins) and instantiating (processes / containers).

4. **[Connecting Processes in separate processes: Topic](/tutorial/multi-process/)** ([Rust](/tutorial/multi-process/rust/), [Python](/tutorial/multi-process/python/), [C++](/tutorial/multi-process/cpp/), [Haskell](/tutorial/multi-process/haskell/), [Zig](/tutorial/multi-process/zig/))

   Make two skeletons, talker and listener, with `juiz pkg create`, start them in separate juiz instances, and connect them with a command. Then make them connect just by starting, through a Topic (publish / subscribe). You learn connect, the other way to use a Process, and Execution Contexts.

5. **[Connecting several libraries in one juiz: connect and Execution Context](/tutorial/connect/)** ([Rust](/tutorial/connect/rust/), [Python](/tutorial/connect/python/), [C++](/tutorial/connect/cpp/), [Haskell](/tutorial/connect/haskell/), [Zig](/tutorial/connect/zig/))

   Load the two libraries from chapter 4 into one juiz and connect them with `connections` and an Execution Context in the configuration file. You learn Push and Pull, and the difference between call and running from an EC.

6. **[Packaging as a Component](/tutorial/component/)**

   Compare the Component form the skeleton used with one file per type in the example repository. You learn that a Component is the unit of distribution.

7. **[Choosing a transport: the IPC broker](/tutorial/ipc-broker/)**

   Reconnect the talker and listener of chapter 4 through the IPC broker instead of HTTP. You learn that the transport is a broker you can swap, and that the start of an ID tells which one is used. The Zenoh broker for other machines and other options such as QUIC are introduced too.

8. **[Data types: agreeing on a type across languages](/tutorial/datatype/)**

   Write pose and velocity types in the IDL, generate the types for each language, and use them in Processes. You learn that types generated from the same IDL connect across languages, and that a connection between mismatched types is an error.

</Steps>

## How to read each chapter

- Each chapter starts with "What you will learn" and ends with a "Summary".
- **Chapters 1, 2 and 4 to 6 have a separate page for each language.** You create your own project skeleton with `juiz pkg create`, and learn how to read `Cargo.toml` (Rust), `pyproject.toml` (Python), `CMakeLists.txt` (C++), `cabal.project` and the `.cabal` file (Haskell), or `build.zig` and `build.zig.zon` (Zig), and the source with the types.
- Chapter 3 keeps using the project from chapters 1 and 2.
- Chapters 4 and 5 make the talker and the listener from `juiz pkg create` skeletons, as in chapter 1. From chapter 6 on, you clone and use the example repositories ([Rust](https://github.com/OpenJUIZ/juiz_examples_rust), [Python](https://github.com/OpenJUIZ/juiz_examples_python), [C++](https://github.com/OpenJUIZ/juiz_examples_cpp), [Haskell](https://github.com/OpenJUIZ/juiz_examples_haskell), [Zig](https://github.com/OpenJUIZ/juiz_examples_zig)). Each chapter links to the corresponding files.
- From chapter 3 on, code examples can be switched between Rust, Python, C++, Haskell and Zig with tabs. The language you pick is kept on every other page.
- The meanings of terms such as Process, Container, call, execute, call_partial and p_apply are collected in the [Glossary](/concepts/glossary/).
- If you already know what you want to do, you can also look it up in the [Guides](/guides/process/).
- Separately from the tutorial, there is [Try it](/try/), where you run ready-made juiz apps to do robot-like things.

## Before you start

Install the `juiz` command by following [Installation](/getting-started/install/), and the package for the language you use by following [Language packages](/getting-started/packages/).
`juiz pkg`, used in chapter 1, comes with juiz 0.2.6 and later.

- For Rust, install the `juiz` command with `cargo install juiz_app`.
- If you use only Python, chapter 1 installs `juiz-cli` into a working venv, so you do not need to install it beforehand. No Rust toolchain is needed.
- For C++, besides the `juiz` command (installed with either pip or cargo), you need CMake and a C++17 compiler. Chapter 1 sets up libjuiz_sdk.
- For Haskell, besides the `juiz` command, you need GHC 9.6 or later and cabal (Linux or macOS). Chapter 1 sets up libjuiz_sdk and hsjuiz. Building the examples from chapter 6 on also uses Rust.
- For Zig, besides the `juiz` command, you need Zig 0.17.x (Linux or macOS). Chapter 1 installs libjuiz_sdk with `juiz sdk install`, and the skeleton's script fetches zigjuiz. Building the examples from chapter 6 on also uses Rust. Zig is available from juiz 0.3.3 (see "Zig" in [Language packages](/getting-started/packages/#zig)).

When you are ready, move on to [Your first Process](/tutorial/first-process/).
