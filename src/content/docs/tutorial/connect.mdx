In chapter 4 you started the talker and the listener in separate juiz instances and connected them over HTTP.
For parts that always run together on the same computer, you can also load both libraries into one juiz and connect them there. The values are passed inside the same process, with no communication cost.
In this chapter you list the two libraries from chapter 4 in one configuration file and connect them with `connections` and an Execution Context.

<Aside type="tip" title="What you will learn">
- Libraries made separately can be loaded side by side into one juiz
- Connecting Processes with `connections` in a configuration file (**connect**), and the difference between `Push` and `Pull`
- When a Process runs is decided by an **Execution Context** (EC), not by the Process itself
- The difference between call and running from an EC
</Aside>

You use the `talker` and `listener` skeletons from chapter 4. Where the libraries are differs by language, so pick your language.
