In this first chapter you start from an empty directory and run a Process that just adds 1 to its argument and returns it.
The code you write is a single short function, but juiz loads it and turns it into a building block you can call over the network.

<Aside type="tip" title="What you will learn">
- How to set up a project for writing Processes (how to write `Cargo.toml`, `pyproject.toml`, `CMakeLists.txt` or the `.cabal` file)
- A Process is an idempotent function that takes arguments and returns a result
- A Process has a "type name" and an "instance name"
- How to call a Process from outside and get the result back (call)
</Aside>

How you set up a project differs a lot between languages, so this chapter and chapter 2 have a separate page for each language. Pick the one you use.

You grow the project you create here: chapter 2 adds a Container, and chapter 3 adds a configuration file.
The file names and locations match the examples ([Rust](https://github.com/OpenJUIZ/juiz_examples_rust), [Python](https://github.com/OpenJUIZ/juiz_examples_python), [C++](https://github.com/OpenJUIZ/juiz_examples_cpp), [Haskell](https://github.com/OpenJUIZ/juiz_examples_haskell)), so if you get stuck, compare your files with the ones in the same place in the examples.
