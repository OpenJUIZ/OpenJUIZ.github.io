In this first chapter you create a project skeleton with `juiz pkg create` and run the Process in it, which adds two numbers and returns the sum.
The skeleton comes with the build settings, the Process code and the start-up configuration file already in place, so a few commands give you a building block you can call over the network.
While running it, you read what each file in the skeleton does.

<Aside type="tip" title="What you will learn">
- How to create a project skeleton for writing Processes with `juiz pkg create`
- How to read the skeleton (the build settings, the Process code and the start-up configuration file `app/app.conf`)
- A Process is an idempotent function that takes arguments and returns a result
- A Process has a "type name" and an "instance name"
- How to call a Process from outside and get the result back (call)
</Aside>

<Aside type="caution" title="juiz 0.2.6 or later is required">
`juiz pkg` is available from juiz 0.2.6. Check with `juiz --version`.
</Aside>

The skeleton's options and the steps up to distributing it as a `.juizapp` are in the guide [Starting from a skeleton (juiz pkg)](/guides/pkg/).
