整数の値を一つ持つ Container と、その値に引数を足す ContainerProcess を例にします。

## Container

<Tabs syncKey="lang">
<TabItem label="Rust">

```rust
use juiz_sdk::prelude::*;

#[repr(Rust)]
pub struct ExampleContainer {
    pub value: i64
}

#[juiz_container]
fn example_container(initial_value: i64) -> JuizResult<Box<ExampleContainer>> {
    Ok(Box::new(ExampleContainer { value: initial_value }))
}
```

</TabItem>
<TabItem label="C++">

```cpp
// example_container.h
#pragma once
#include <cstdint>

class CppContainer {
public:
    int64_t value;
    CppContainer(int64_t v) : value(v) {}
};
```

```cpp
// example_container_cpp.cpp
#include "juiz/juiz.h"
#include "example_container.h"

juiz::Value manifest() {
    return ContainerManifest("example_container_cpp").into_value();
}

CppContainer* create_container(juiz::Value value) {
    int64_t int_value = 0;
    if (value.isObjectValue() && value.hasKey("value")) {
        auto v = value.objectValue()["value"];
        if (v.isIntValue()) int_value = v.intValue();
    }
    return new CppContainer(int_value);
}

bool destroy_container(CppContainer* p_container) {
    if (p_container) {
        delete p_container;
        return true;
    }
    return false;
}

CONTAINER_FACTORY(manifest, create_container, destroy_container);
```

</TabItem>
<TabItem label="Python">

```python
from juiz import *

class PyContainer:
    value: int
    def __init__(self, value):
        self.value = value

@juiz_container
def example_container_python(initial_value: int = 0) -> PyContainer:
    return PyContainer(initial_value)
```

</TabItem>
<TabItem label="Haskell">

```haskell
-- ExampleContainerState.hs: 状態の型 (Container と ContainerProcess の両方のライブラリに入れる)
module ExampleContainerState (ExampleContainer (..)) where

import Data.IORef (IORef)
import Data.Int (Int64)

newtype ExampleContainer = ExampleContainer (IORef Int64)
```

```haskell
-- ExampleContainer.hs
{-# LANGUAGE OverloadedStrings #-}
{-# LANGUAGE TemplateHaskell #-}
module ExampleContainer () where

import Juiz
import ExampleContainerState

manifest :: ContainerManifest
manifest = containerManifest "example_container_hs"
  & addIntArg "value" "initial value" 0

create :: Int64 -> IO ExampleContainer
create value = ExampleContainer <$> newIORef value

juizContainer 'create 'manifest
```

`containerManifest` の引数は、Container を作る関数の引数になります(設定ファイルの `containers` に書いた値を受け取ります)。書き換える値は `IORef` に入れます。

</TabItem>
</Tabs>

## ContainerProcess

ContainerProcess は、最初の引数に Container を受け取る Process です。`container_type` で結びつける Container の型名を指定します。

<Tabs syncKey="lang">
<TabItem label="Rust">

```rust
use example_container::ExampleContainer;
use juiz_sdk::prelude::*;

#[juiz_container_process(container_type = "example_container")]
fn increment_function(container: &mut ContainerImpl<ExampleContainer>, arg1: i64) -> JuizResult<Capsule> {
    container.value = container.value + arg1;
    return Ok(jvalue!(container.value).into());
}
```

</TabItem>
<TabItem label="C++">

```cpp
#include "juiz/juiz.h"
#include "example_container.h"

juiz::Value manifest() {
    return ProcessManifest("example_container_cpp_increment")
        .container_type("example_container_cpp")
        .add_int_arg("arg0", "test_argument", 2)
        .into_value();
}

std::optional<int64_t> example_container_increment(CppContainer* container, juiz::CapsuleMap cm) {
    int64_t v = cm.get_int("arg0");
    container->value = container->value + v;
    return container->value;
}

CONTAINER_PROCESS_FACTORY(CppContainer, manifest, example_container_increment)
```

</TabItem>
<TabItem label="Python">

```python
from juiz import juiz_container_process

@juiz_container_process(container_type="example_container_python")
def example_container_python_get(container) -> int:
    return container.value
```

</TabItem>
<TabItem label="Haskell">

```haskell
{-# LANGUAGE OverloadedStrings #-}
{-# LANGUAGE TemplateHaskell #-}
module ExampleContainerIncrement () where

import Juiz
import ExampleContainerState

manifest :: ProcessManifest
manifest = containerProcessManifest "example_container_hs_increment" "example_container_hs"
  & addIntArg "arg1" "value to be added" 1

increment :: ExampleContainer -> Int64 -> IO Int64
increment (ExampleContainer ref) arg1 = atomicModifyIORef' ref (\v -> (v + arg1, v + arg1))

juizContainerProcess 'increment 'manifest
```

`containerProcessManifest` の 2 つ目の引数が、結びつける Container の型名です。
状態の型は、Container と ContainerProcess のライブラリで同じモジュールの同じ型を使ってください(型が違うとエラーになります)。1 つのライブラリにまとめる場合は `juizComponent` を使います([チュートリアル第 5 章(Haskell)](/ja/tutorial/component/haskell/))。

</TabItem>
</Tabs>

## 単体で動かす

<Tabs syncKey="platform">
<TabItem label="Linux">

```sh
juiz --container ./target/debug/libexample_container.so \
     --container_process ./target/debug/libexample_container_increment.so \
     -l rust -e -1 -d
```

</TabItem>
<TabItem label="macOS">

```sh
juiz --container ./target/debug/libexample_container.dylib \
     --container_process ./target/debug/libexample_container_increment.dylib \
     -l rust -e -1 -d
```

</TabItem>
<TabItem label="Windows">

```powershell
juiz --container ./target/debug/example_container.dll `
     --container_process ./target/debug/example_container_increment.dll `
     -l rust -e -1 -d
```

Windows では、ファイル名の先頭に `lib` が付きません。

</TabItem>
</Tabs>
