引数に 1 を足して返すだけの Process を例にします。関数（または manifest）の名前が Process の型名になります。

<Tabs syncKey="lang">
<TabItem label="Rust">

```rust
use juiz_sdk::prelude::*;

#[juiz_process]
fn increment_process(arg1: i64) -> JuizResult<Capsule> {
    log::trace!("increment_process({:?}) called", arg1);
    return Ok(jvalue!(arg1 + 1).into());
}
```

`#[juiz_process]` マクロを付けた関数が Process の本体になります。
引数は複数使えて、`i64`、`f64`、`bool`、`String`、`Value`、`Vec<Value>` などを受け取れます。引数の名前がそのままパラメータ名になります。

</TabItem>
<TabItem label="C++">

```cpp
#include "juiz/juiz.h"

juiz::Value manifest() {
    return ProcessManifest{"increment_process_cpp"}
        .add_int_arg("arg1", "test_argument", 1)
        .into_value();
}

std::optional<int64_t> increment_process(juiz::CapsuleMap cm) {
    auto a = cm.get_int("arg1");
    return a + 1;
}

PROCESS_FACTORY(manifest, increment_process);
```

C++ では manifest（型名と引数の定義）を自分で書き、`PROCESS_FACTORY` で公開します。

</TabItem>
<TabItem label="Python">

```python
from juiz import *

@juiz_process
def increment_process(arg1: int = 1) -> int:
    return arg1 + 1
```

`@juiz_process` デコレータを付けるだけで Process になります。独自のデータ型は dataclass で定義し、出力では `asdict` で dict に変換して返します。

</TabItem>
<TabItem label="Haskell">

```haskell
{-# LANGUAGE OverloadedStrings #-}
{-# LANGUAGE TemplateHaskell #-}
module IncrementProcess () where

import Juiz

manifest :: ProcessManifest
manifest = processManifest "increment_process_hs"
  & description "Adds 1 to arg1."
  & addIntArg "arg1" "value to be incremented" 1

increment :: Int64 -> IO Int64
increment arg1 = pure (arg1 + 1)

juizProcess 'increment 'manifest
```

Haskell では hsjuiz を使い、manifest(型名と引数の定義)を自分で書いて、`juizProcess` で公開します。引数は manifest に足した順に関数へ渡されます。
結果は `IO r` でも、IO の付かない `r` でもかまいません。cabal の `foreign-library`(`type: native-shared`、`ghc-options: -threaded`)で共有ライブラリとしてビルドします。
使える型やエラーの返し方は [hsjuiz の README](https://github.com/OpenJUIZ/juiz/tree/main/bindings/hsjuiz)、プロジェクトの作り方は [チュートリアル第 1 章(Haskell)](/ja/tutorial/first-process/haskell/) にあります。

</TabItem>
</Tabs>

## 単体で動かす

ビルドしたファイルを `--process` で指定し、`-e` で実体化して実行します。

<Tabs syncKey="platform">
<TabItem label="Linux">

```sh
juiz --process target/debug/libincrement_process.so -l rust -e -1 -d
```

</TabItem>
<TabItem label="macOS">

```sh
juiz --process target/debug/libincrement_process.dylib -l rust -e -1 -d
```

</TabItem>
<TabItem label="Windows">

```powershell
juiz --process target/debug/increment_process.dll -l rust -e -1 -d
```

</TabItem>
</Tabs>

- `-l` は言語（`rust` / `cpp` / `python` / `haskell`、既定は `rust`）
- `-e` はロードした Process を一つ実体化し、既定の引数で実行
- `-1` はロードしたモジュールごとにインスタンスを一つ作成
- `-d` は実行後に HTTP ブローカーを立てて待機
