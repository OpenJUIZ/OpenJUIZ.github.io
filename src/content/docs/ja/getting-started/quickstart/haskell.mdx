Haskell のサンプル集 [juiz_examples_haskell](https://github.com/OpenJUIZ/juiz_examples_haskell) を使って、引数に 1 を足すだけの Process を動かしてみます。
先に [インストール](/ja/getting-started/install/) で `juiz` コマンドを入れておいてください。

## サンプルをビルドする

必要なもの:

- Linux または macOS
- GHC 9.6 以降と cabal([GHCup](https://www.haskell.org/ghcup/) でインストール)
- Rust(stable)。サンプルの型を作る juiz-idl のビルドに使います
- git、curl

```sh
git clone https://github.com/OpenJUIZ/juiz_examples_haskell.git
cd juiz_examples_haskell
./build.sh
```

`build.sh` が、`juiz` と同じ版の libjuiz_sdk と hsjuiz(Haskell 用のライブラリ)の取得から、サンプルのビルドまでを行います。初回は少し時間がかかります。
各サンプルは共有ライブラリとして `build/plugins` にビルドされます。
macOS でリンクに失敗するときは、サンプル集の [README](https://github.com/OpenJUIZ/juiz_examples_haskell#readme) を見てください。

## Process のコード

動かすのは、次の Process です。

[`process/IncrementProcess.hs`](https://github.com/OpenJUIZ/juiz_examples_haskell/blob/main/process/IncrementProcess.hs)

```haskell
{-# LANGUAGE OverloadedStrings #-}
{-# LANGUAGE TemplateHaskell #-}
module IncrementProcess () where

import Juiz

manifest :: ProcessManifest
manifest = processManifest "increment_process_hs"
  & description "Adds 1 to arg1."
  & addIntArg "arg1" "value to be incremented" 1

increment :: Int64 -> IO Int64
increment arg1 = pure (arg1 + 1)

juizProcess 'increment 'manifest
```

## 起動する

リポジトリのルートで、設定ファイルを指定して `juiz` を起動します。設定ファイルは、リポジトリのルートからの相対パスでプラグインを探します。

```sh
juiz -f increment_process.conf -d
```

`-d` を付けると、HTTP ブローカーを 8000 番ポートで立ち上げて待機します(Ctrl+C で終了)。

## 呼び出す

`juiz` を起動したまま、別のターミナルを開いて、同じディレクトリで呼び出します。

```sh
juiz process list
# => ["http://127.0.0.1:8000/process/increment0::increment_process_hs"]
juiz process call "http://127.0.0.1:8000/process/increment0::increment_process_hs" '{"arg1": 3}' -p
# => CapsulePtr((value:Value(4), option: []))
```

`3` を渡して `4` が返ってきました。

### ブラウザから呼び出す

ブラウザで次の URL を開くと、Swagger UI から Process を呼び出して結果を確かめられます。

```
http://127.0.0.1:8000/docs/
```

`PATCH /api/process/call` を開き、「Try it out」を押して、identifier に `core://core/process/increment0::increment_process_hs`、Request body に `{"arg1": 3}` を入れて「Execute」を押します。

### 管理画面で見る

次の URL を開くと、動いている Process や接続を管理画面で確かめられます。詳しくは [管理画面](/ja/guides/web-ui/) を見てください。

```
http://127.0.0.1:8000/ui/
```
