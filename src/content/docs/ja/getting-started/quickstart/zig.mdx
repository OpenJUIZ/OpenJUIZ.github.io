Zig のサンプル集 [juiz_examples_zig](https://github.com/OpenJUIZ/juiz_examples_zig) を使って、引数に 1 を足すだけの Process を動かしてみます。

[インストール](/ja/getting-started/install/) の手順で、0.3.3 以降の `juiz` コマンドを入れておいてください。

## サンプルをビルドする

必要なもの:

- Linux、macOS、Windows(x86_64)のいずれか。Windows では Git Bash で `./build.sh` を実行します
- Zig 0.17.x([ziglang.org](https://ziglang.org/download/) から入れる。zigjuiz は Zig の版を 1 つだけに対応しています)
- git

```sh
git clone https://github.com/OpenJUIZ/juiz_examples_zig.git
cd juiz_examples_zig
./build.sh
```

`build.sh` が、juiz の GitHub Releases からの zigjuiz と libjuiz_sdk の取得から、サンプルのビルドまでを行います。初回は少し時間がかかります。
各サンプルは共有ライブラリとして `build/plugins` にビルドされ、libjuiz_sdk も同じ場所に置かれます。
`pip install ziglang==0.17.1` で入れた Zig を使うときは、`ZIG="python3 -m ziglang" ./build.sh` で実行します。

## Process のコード

動かすのは、次の Process です。

[`process/increment_process_zig.zig`](https://github.com/OpenJUIZ/juiz_examples_zig/blob/main/process/increment_process_zig.zig)

```zig
const std = @import("std");
const juiz = @import("juiz");

/// 引数は 1 つの struct で受ける。フィールドの名前・型・既定値が、そのままマニフェストの引数になる
fn increment(args: struct { arg1: i64 = 1 }) !i64 {
    // i64 の最大値に足すと error.Overflow を返す (juiz にはエラーとして返る)
    return std.math.add(i64, args.arg1, 1);
}

comptime {
    juiz.exportProcess(increment, .{
        .type_name = "increment_process_zig",
        .description = "Adds 1 to arg1.",
        .args = .{ .arg1 = "value to be incremented" },
    });
}
```

## 起動する

リポジトリのルートで、設定ファイルを指定して `juiz` を起動します。設定ファイルは、リポジトリのルートからの相対パスでプラグインを探します。

```sh
juiz -f increment_process.conf -d
```

`-d` を付けると、HTTP ブローカーを 8000 番ポートで立ち上げて待機します(Ctrl+C で終了)。

## 呼び出す

`juiz` を起動したまま、別のターミナルを開いて、同じディレクトリで呼び出します。

```sh
juiz process list
# => ["http://127.0.0.1:8000/process/increment0::increment_process_zig"]
juiz process call "http://127.0.0.1:8000/process/increment0::increment_process_zig" '{"arg1": 3}' -p
# => CapsulePtr((value:Value(4), option: []))
```

`3` を渡して `4` が返ってきました。

### ブラウザから呼び出す

ブラウザで次の URL を開くと、Swagger UI から Process を呼び出して結果を確かめられます。

```
http://127.0.0.1:8000/docs/
```

`PATCH /api/process/call` を開き、「Try it out」を押して、identifier に `core://core/process/increment0::increment_process_zig`、Request body に `{"arg1": 3}` を入れて「Execute」を押します。

### 管理画面で見る

次の URL を開くと、動いている Process や接続を管理画面で確かめられます。詳しくは [管理画面](/ja/guides/web-ui/) を見てください。

```
http://127.0.0.1:8000/ui/
```
