ここでは、juiz で作られたアプリを組み合わせて、シミュレータの中の移動ロボットを動かしてみます。
コードを書いたりビルドしたりはしません。配布されている `.juizapp` を取ってきて、ダブルクリックで起動するだけです。

1. キーボードやゲームパッドでロボットを走らせ、
2. LiDAR とオドメトリから **SLAM**(Simultaneous Localization and Mapping、自己位置の推定と地図づくりを同時に行う技術)で部屋の地図を作り、
3. 最後に、その地図の上でロボットがゴールまで自分で走る**自律移動**(ナビゲーション)をさせます。

[チュートリアル](/ja/tutorial/) が「juiz の機能を 1 つずつ学ぶ」ためのものなのに対して、ここは「できあがったものを動かして、全体がどうつながっているかを見る」ためのものです。チュートリアルを終えていなくても始められます。

<Aside type="tip" title="この一巡りでわかること">
- 別々に配布された juiz アプリが、トピックと ID でつながって 1 つのロボットシステムになる様子
- オドメトリ(車輪の回転から求めた位置)にはずれが積み重なり、SLAM や自己位置推定がそれを地図と照らし合わせて直す様子
- 座標系(Transformations)が別々のアプリをまたいで 1 本の木になる様子
- トピックで流し続けるもの(センサーの値、速度の指令)と、HTTP で呼ぶもの(ゴール、経路、地図)の使い分け
</Aside>

## 使うアプリと準備

どのアプリも OpenJUIZ で公開しています。navigation_manager 以外は `.juizapp` です。

<Steps>

1. `juiz` コマンドと navigation_manager を pip で入れます(venv の作り方は [インストール](/ja/getting-started/install/#juiz-コマンドを入れる) にあります)。

   ```sh
   pip install juiz-cli==0.3.0 navigation-manager==0.3.5
   ```

   `juiz` と `navigation-manager` の 2 つのコマンドが使えるようになります。
   mapper_gmapping と localization_amcl は C++ のアプリで、パッケージに `juiz: "=0.3.0"` と書いてあり、juiz 0.3.0 でしか起動しません。版はこのとおりに指定してください。

2. `.juizapp` をダブルクリックで起動できるようにします。venv に入れた場合は、その venv を有効にしたターミナルで 1 回だけ実行します。

   ```sh
   juiz associate
   ```

   詳しくは [インストール: .juizapp をダブルクリックで開けるようにする](/ja/getting-started/install/#juizapp-をダブルクリックで開けるようにする) にあります。

3. 作業用のフォルダ `try_juiz` を作ります。ダウンロードした `.juizapp` と、2 で作る地図をここに置きます。

4. 次の表の「ダウンロード」から、7 つの `.juizapp` を `try_juiz` にダウンロードします。

## アプリの起動のしかた

`.juizapp` は、ファイルをダブルクリックして起動します。

ダブルクリックすると新しいターミナルの窓が開き、その中で `juiz run` が動きます。窓のタイトルは `juiz - <アプリの名前> <版>` になります。
アプリはこの窓が開いている間だけ動きます。止めるときは窓を閉じるか、窓の中で Ctrl+C を押します。

<Aside type="note" title="macOS で初めてダブルクリックしたとき">
「JUIZ Launcher が Terminal を制御しようとしています」と確認が出るので、許可してください。
</Aside>

### うまく起動したとき(OK)

mobile_sim なら、窓に次のように出て、そのまま止まります(パスは環境によって変わります)。

```text
Running mobile_sim 0.3.6 from /home/you/.cache/juiz/apps/mobile_sim-0.3.6-fd2fb57c16789ce6
Close this window or press Ctrl+C to stop.
juiz 管理画面: http://localhost:8000/ui/
IPC broker: ipc://mobile_sim
HTTP broker: http://127.0.0.1:8000/
```

最後に `HTTP broker: http://127.0.0.1:<番号>/` が出て、`error:` で始まる行が無く、窓が開いたままなら OK です。`<番号>` は上の表のアプリ名の下にある URL の番号です。
各ページには、そのアプリが OK のときの表示を載せています。

### うまく起動しなかったとき(NG)

- **`error:` で始まる行と `Press Enter to close.` が出た**: 起動に失敗しています。エラーの文を読んでから Enter で窓を閉じます。よくあるものは次のとおりです。

  | 表示 | 原因と直し方 |
  | --- | --- |
  | `error: mobile_sim is already running at ipc://mobile_sim.` | 同じアプリがもう動いています。前に開いた窓を探して使うか、閉じてから起動し直します |
  | `error: mapper_gmapping 0.4.3 requires juiz =0.3.0, but this is juiz 0.2.11.` | juiz の版が合っていません。手順 1 の版(`juiz-cli==0.3.0`)で入れ直してから、`juiz associate` をもう一度実行します(別の venv の juiz に関連付けられていることもあります) |

- **`depends on mobile_sim ... but it is not running` と番号つきの選択が出た**: 頼りにしている mobile_sim が動いていません。mobile_sim を先にダブルクリックして起動してから、この窓で `retry` の番号を入れて Enter を押します。
  ```text
  teleop_twist depends on mobile_sim >=0.3.1, <0.4, but it is not running at ipc://mobile_sim.
    1) enter where mobile_sim is (ex., http://192.168.0.10:8100)
    2) retry
    3) quit
  choose [1]:
  ```
- **窓が開いてすぐ消えた、何も起きない、別のアプリ(圧縮ファイルを開くアプリなど)が開いた、「このファイルを開く方法」を聞かれた**: `.juizapp` が juiz に関連付けられていません。
  - `juiz` コマンドが入っていなければ、[インストール: juiz コマンドを入れる](/ja/getting-started/install/#juiz-コマンドを入れる) からやり直します。
  - 入っていれば、[インストール: .juizapp をダブルクリックで開けるようにする](/ja/getting-started/install/#juizapp-をダブルクリックで開けるようにする) の `juiz associate` を実行します。OS ごとの違いは [ガイド: ダブルクリックで起動する](/ja/guides/app-package/#ダブルクリックで起動する) にあります。

<Aside type="tip" title="ターミナルから起動してもかまいません">
ダブルクリックの代わりに、`try_juiz` で開いたターミナルで `juiz run mobile_sim-0.3.6.juizapp` のように実行しても同じです(`Close this window ...` の行だけは出ません)。止めるときは Ctrl+C です。
</Aside>

## ターミナル

アプリはダブルクリックでそれぞれの窓に起動するので、ターミナルは `juiz` コマンドで中を見るときと、後半の一式の起動に使います。pip で venv に入れた場合は、ターミナルで venv を有効にしておきます。

| | 1〜3(地図を作る) | 4〜6(自律移動) |
| --- | --- | --- |
| アプリ | mobile_sim、teleop_twist、mapper_gmapping をダブルクリック(それぞれの窓) | ターミナル 1 で一式(`navigation-manager stack`)。`try_juiz` で開く |
| 中を見る | ターミナル 1 つで `juiz` コマンド | ターミナル 2 で `juiz` コマンドなど |

<Aside type="note" title="読んでおくとよい章">

- [第 4 章 別々のプロセスで動く Process をつなぐ](/ja/tutorial/multi-process/): トピック、副系(subsystem)と ID
- [第 5 章 1 つの juiz で複数のライブラリをつなぐ](/ja/tutorial/connect/): Execution Context
- [第 8 章 データ型](/ja/tutorial/datatype/): `Twist2D` などの型

- [ガイド: アプリの配布(.juizapp)](/ja/guides/app-package/): `juiz run` と `depends`
</Aside>
