このチュートリアルでは、`juiz pkg create` で作る雛形の、2 つの数を足すだけの小さな Process から始めて、少しずつ題材を育てながら juiz の考え方を学びます。
各章は「動かしてみる」ことを中心にしていて、手を動かしながら読み進められるようにしてあります。

## 章の構成

<Steps>

1. **[はじめての Process](/ja/tutorial/first-process/)**([Rust](/ja/tutorial/first-process/rust/)・[Python](/ja/tutorial/first-process/python/)・[C++](/ja/tutorial/first-process/cpp/)・[Haskell](/ja/tutorial/first-process/haskell/)・[Zig](/ja/tutorial/first-process/zig/))

   `juiz pkg create` で雛形のプロジェクトを作り、2 つの数を足す Process のコードを読んでから動かし、管理画面とターミナルから呼び出して結果を受け取ります。雛形の中身の読み方と、Process が冪等な関数であること、call という使い方を学びます。

2. **[状態を持つ: Container と ContainerProcess](/ja/tutorial/container/)**([Rust](/ja/tutorial/container/rust/)・[Python](/ja/tutorial/container/python/)・[C++](/ja/tutorial/container/cpp/)・[Haskell](/ja/tutorial/container/haskell/)・[Zig](/ja/tutorial/container/zig/))

   `juiz pkg add container` でカウンタを足し、状態を Container に置き、ContainerProcess だけがそれに触れる設計を学びます。

3. **[設定ファイルでまとめて起動する](/ja/tutorial/config-file/)**(全言語共通)

   雛形の設定ファイル `app/app.conf` を読んで書き換え、インスタンスを増やしたり初期値を渡したりします。読み込み(plugins)と実体化(processes / containers)の違いを学びます。

4. **[別々のプロセスで動く Process をつなぐ: Topic](/ja/tutorial/multi-process/)**([Rust](/ja/tutorial/multi-process/rust/)・[Python](/ja/tutorial/multi-process/python/)・[C++](/ja/tutorial/multi-process/cpp/)・[Haskell](/ja/tutorial/multi-process/haskell/)・[Zig](/ja/tutorial/multi-process/zig/))

   `juiz pkg create` で talker と listener の 2 つの雛形を作り、別々の juiz で起動して、コマンドでつなぎます。続けて、Topic(publish / subscribe)で、起動するだけでつながるようにします。connect というもう一つの使い方と、Execution Context を学びます。

5. **[1 つの juiz で複数のライブラリをつなぐ: connect と Execution Context](/ja/tutorial/connect/)**([Rust](/ja/tutorial/connect/rust/)・[Python](/ja/tutorial/connect/python/)・[C++](/ja/tutorial/connect/cpp/)・[Haskell](/ja/tutorial/connect/haskell/)・[Zig](/ja/tutorial/connect/zig/))

   第 4 章の 2 つのライブラリを 1 つの juiz に読み込み、設定ファイルの `connections` と Execution Context でつなぎます。Push と Pull、call と EC による実行の違いを学びます。

6. **[Component にまとめて配布する](/ja/tutorial/component/)**

   雛形がとっていた Component の形を、サンプル集の型ごとのファイルと比べます。Component が配布の単位であることを学びます。

7. **[通信方式を選ぶ: IPC ブローカー](/ja/tutorial/ipc-broker/)**

   第 4 章の talker と listener を、HTTP の代わりに IPC ブローカーでつなぎ直します。通信方式はブローカーとして差し替えられ、ID の先頭がそれを表すことを学びます。別のマシンとつなぐ Zenoh ブローカーと、QUIC などほかの選択肢にも触れます。

8. **[データ型: 型を決めて言語をまたいでつなぐ](/ja/tutorial/datatype/)**

   姿勢と速度の型を IDL で書き、各言語の型を生成して Process で使います。同じ IDL から作った型は言語が違ってもそのままつながり、型の合わない接続はエラーになることを学びます。

</Steps>

## 各章の読み方

- 章の最初に「この章で学ぶこと」、最後に「まとめ」があります。
- **第 1・2 章と第 4〜6 章は、言語ごとのページに分かれています。** `juiz pkg create` で自分のプロジェクトの雛形を作り、`Cargo.toml`(Rust)・`pyproject.toml`(Python)・`CMakeLists.txt`(C++)・`cabal.project` と `.cabal`(Haskell)・`build.zig` と `build.zig.zon`(Zig)や、型を書いたソースの読み方を説明します。
- 第 3 章は、第 1・2 章で作ったプロジェクトをそのまま使います。
- 第 4・5 章は、第 1 章と同じく `juiz pkg create` の雛形で talker と listener を作ります。第 6 章からは、サンプル集([Rust](https://github.com/OpenJUIZ/juiz_examples_rust)・[Python](https://github.com/OpenJUIZ/juiz_examples_python)・[C++](https://github.com/OpenJUIZ/juiz_examples_cpp)・[Haskell](https://github.com/OpenJUIZ/juiz_examples_haskell)・[Zig](https://github.com/OpenJUIZ/juiz_examples_zig))をクローンして使います。各章に対応するファイルへのリンクを置いています。
- 第 3 章以降のコード例は Rust・Python・C++・Haskell・Zig のタブで切り替えられます。一度選んだ言語は、ほかのページでもそのまま保たれます。
- 用語(Process・Container・call・execute・call_partial・p_apply など)の意味は [用語集](/ja/concepts/glossary/) にまとめてあります。
- やりたいことが決まっているときは、[ガイド](/ja/guides/process/) から逆引きで探すこともできます。
- チュートリアルとは別に、できあがった juiz アプリを動かしてロボットらしいことをやってみる [使ってみる](/ja/try/) もあります。

## 準備

[インストール](/ja/getting-started/install/) の手順で `juiz` コマンドを、[言語ごとのパッケージ](/ja/getting-started/packages/) の手順で使う言語のパッケージを入れておいてください。
第 1 章で使う `juiz pkg` は juiz 0.2.6 から入っています。

- Rust で進める場合は `cargo install juiz_app` で `juiz` コマンドを入れます。
- Python だけで進める場合は、第 1 章で作業用の venv に `juiz-cli` を入れるので、先に入れておく必要はありません。Rust のツールチェーンも要りません。
- C++ で進める場合は、`juiz` コマンド(pip と cargo のどちらで入れてもかまいません)のほかに、CMake と C++17 対応のコンパイラが必要です。libjuiz_sdk は第 1 章で用意します。
- Haskell で進める場合は、`juiz` コマンドのほかに、GHC 9.6 以降と cabal が必要です(Linux・macOS)。libjuiz_sdk と hsjuiz は第 1 章で用意します。第 6 章からのサンプル集のビルドには Rust も使います。
- Zig で進める場合は、`juiz` コマンドのほかに、Zig 0.17.x が必要です(Linux・macOS)。libjuiz_sdk は第 1 章で `juiz sdk install` で入れ、zigjuiz は雛形のスクリプトが取り込みます。第 6 章からのサンプル集のビルドには Rust も使います。Zig は juiz 0.3.3 から使えます([言語ごとのパッケージの「Zig」](/ja/getting-started/packages/#zig))。

準備ができたら、[はじめての Process](/ja/tutorial/first-process/) に進みましょう。
