このチュートリアルでは、引数に 1 を足すだけの小さな Process から始めて、少しずつ題材を育てながら juiz の考え方を学びます。
各章は「動かしてみる」ことを中心にしていて、手を動かしながら読み進められるようにしてあります。

## 章の構成

<Steps>

1. **[はじめての Process](/ja/tutorial/first-process/)**([Rust](/ja/tutorial/first-process/rust/)・[Python](/ja/tutorial/first-process/python/)・[C++](/ja/tutorial/first-process/cpp/))

   引数に 1 を足す Process を、空のディレクトリから作って動かし、外から呼び出して結果を受け取ります。Process が冪等な関数であることと、call という使い方を学びます。

2. **[状態を持つ: Container と ContainerProcess](/ja/tutorial/container/)**([Rust](/ja/tutorial/container/rust/)・[Python](/ja/tutorial/container/python/)・[C++](/ja/tutorial/container/cpp/))

   カウンタを題材に、状態を Container に置き、ContainerProcess だけがそれに触れる設計を学びます。

3. **[設定ファイルでまとめて起動する](/ja/tutorial/config-file/)**

   これまでの Process と Container を 1 つの設定ファイルで起動します。読み込み(plugins)と実体化(processes / containers)の違いを学びます。

4. **[Process をつなぐ: connect と Execution Context](/ja/tutorial/connect/)**

   talker と listener をつなぎ、Execution Context で周期的に動かします。connect というもう一つの使い方を学びます。

5. **[Component にまとめて配布する](/ja/tutorial/component/)**

   複数の機能要素を 1 つのプロジェクトにまとめます。Component が配布の単位であることを学びます。

6. **[別々のプロセスをつなぐ](/ja/tutorial/multi-process/)**

   別々に起動した juiz どうしを、設定ファイルなしでコマンドからつなぎます。Process が場所を問わず ID(URL)でつながることを学びます。

7. **[通信方式を選ぶ: QUIC ブローカー](/ja/tutorial/quic-broker/)**

   第 6 章の接続を、HTTP の代わりに QUIC ブローカーで行います。通信方式はブローカーとして差し替えられ、ID の先頭がそれを表すことを学びます。

8. **[データ型: 型を決めて言語をまたいでつなぐ](/ja/tutorial/datatype/)**

   姿勢と速度の型を IDL で書き、各言語の型を生成して Process で使います。同じ IDL から作った型は言語が違ってもそのままつながり、型の合わない接続はエラーになることを学びます。

</Steps>

## 各章の読み方

- 章の最初に「この章で学ぶこと」、最後に「まとめ」があります。
- **第 1 章と第 2 章は、言語ごとのページに分かれています。** 空のディレクトリから自分のプロジェクトを作り、`Cargo.toml`(Rust)・`pyproject.toml`(Python)・`CMakeLists.txt`(C++)の書き方から順に説明します。
- 第 3 章は、第 1・2 章で作ったプロジェクトをそのまま使います。
- 第 4 章からは、サンプル集([Rust](https://github.com/OpenJUIZ/juiz_examples_rust)・[Python](https://github.com/OpenJUIZ/juiz_examples_python)・[C++](https://github.com/OpenJUIZ/juiz_examples_cpp))をクローンして使います。各章に対応するファイルへのリンクを置いています。
- 第 3 章以降のコード例は Rust・Python・C++ のタブで切り替えられます。一度選んだ言語は、ほかのページでもそのまま保たれます。
- やりたいことが決まっているときは、[ガイド](/ja/guides/process/) から逆引きで探すこともできます。

## 準備

[インストール](/ja/getting-started/install/) の手順で、`juiz` コマンドと、使う言語のパッケージを入れておいてください。

- Rust で進める場合は `cargo install juiz_app` で `juiz` コマンドを入れます。
- Python だけで進める場合は、第 1 章でプロジェクトの venv に `juiz-cli` を入れるので、先に入れておく必要はありません。Rust のツールチェーンも要りません。
- C++ で進める場合は、`juiz` コマンド(pip と cargo のどちらで入れてもかまいません)のほかに、CMake と C++17 対応のコンパイラが必要です。libjuiz_sdk は第 1 章で用意します。

準備ができたら、[はじめての Process](/ja/tutorial/first-process/) に進みましょう。
