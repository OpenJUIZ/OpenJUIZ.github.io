最初の章では、引数に 1 を足して返すだけの Process を、空のディレクトリから作って動かします。
書くコードは短い関数ひとつですが、juiz はそれを読み込んで、ネットワーク越しに呼び出せる部品にしてくれます。

<Aside type="tip" title="この章で学ぶこと">
- Process を書くプロジェクトの作り方(`Cargo.toml`・`pyproject.toml`・`CMakeLists.txt` の書き方)
- Process は、引数を受け取って結果を返す冪等な関数であること
- Process には「型名」と「インスタンス名」があること
- 外から Process を呼び出して結果を受け取る使い方(call)
</Aside>

この章と次の第 2 章は、プロジェクトの作り方が言語ごとに大きく違うので、言語ごとのページに分けています。使う言語を選んでください。

	<LinkCard title="Python" href="/ja/tutorial/first-process/python/" description="pyproject.toml と venv を用意し、.py ファイルをそのまま読み込ませます。" />

ここで作るプロジェクトは、第 2 章で Container を足し、第 3 章で設定ファイルを足して育てていきます。
ファイルの名前と置き場所は、サンプル集([Rust](https://github.com/OpenJUIZ/juiz_examples_rust)・[Python](https://github.com/OpenJUIZ/juiz_examples_python)・[C++](https://github.com/OpenJUIZ/juiz_examples_cpp))とそろえてあるので、途中で迷ったらサンプル集の同じ場所のファイルと見比べてください。

Haskell の書き方は [hsjuiz の README](https://github.com/OpenJUIZ/juiz/tree/main/bindings/hsjuiz) と [Haskell のクイックスタート](/ja/getting-started/quickstart/haskell/) を見てください。
</Aside>
