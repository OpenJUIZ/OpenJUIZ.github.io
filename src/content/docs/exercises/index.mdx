In the exercises, you combine apps built with juiz to do robot-like things.
While the [tutorial](/tutorial/) teaches the features of juiz one at a time, the exercises let you run finished apps and see how the whole system fits together.

- The apps used in the exercises are distributed as `.juizapp` packages and run with just `juiz run`. You do not need to write or build any code.
- You can start before finishing the whole tutorial. Each exercise lists what to prepare first, and the chapters worth reading for a deeper understanding.
