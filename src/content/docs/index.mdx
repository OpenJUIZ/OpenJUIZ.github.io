JUIZ lets you write software that drives cameras, robots, motors and sensors in several languages,
then combine those pieces so they run together as a single software service.

<CardGrid stagger>
	<Card title="Process" icon="rocket">

	</Card>
	<Card title="Container" icon="puzzle">

	</Card>
	<Card title="connect and call" icon="random">

## Try it

With Python 3.10 or later, `pip install` is all you need (no Rust toolchain).

```sh
git clone https://github.com/OpenJUIZ/juiz_examples_python.git && cd juiz_examples_python
python3 -m venv .venv && source .venv/bin/activate
pip install juiz-cli
juiz -f increment_process.conf -d
```

In another terminal, activate the same venv and call the Process.

```sh
juiz process call "http://127.0.0.1:8000/process/increment0::increment_process_python" '{"arg1": 3}' -p
# => CapsulePtr((value:Value(4), option: []))
```

To write in Rust or C++, install `juiz` with `cargo install juiz_app`. See [Installation](/getting-started/install/) for details.
